# Tribute Page Project

A beginner-friendly tribute page made with HTML and CSS.

## Features

- Hero section
- Tribute image
- About section
- Quote section
- Timeline
- Values/lessons section
- Responsive design for mobile and desktop

## Files

- `index.html` - Page structure and tribute content
- `style.css` - Styling, layout, typography, colors, and responsive design

## How to Run

Open `index.html` in your browser.

You can also use the VS Code Live Server extension while editing.

## Customize

You can replace the example tribute with someone you admire. Update these parts in `index.html`:

- Person name
- Image URL
- About paragraph
- Quote
- Timeline events
- Values or achievements

## How to Push to GitHub

```bash
git init
git add .
git commit -m "Add tribute page project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with your GitHub account and repository name.
